# Cabang (Outlet)

Menu **Cabang (Outlet)** mengelola lokasi-lokasi toko Anda. Setiap outlet memiliki data, stok, harga, shift, dan kode aksesnya sendiri.

<Callout type="info" title="Istilah outlet">
  "Outlet" = cabang/lokasi toko. Satu akun bisa memiliki beberapa outlet (misal cabang Tebet dan cabang Blok M).
</Callout>

## Menambahkan cabang

1. Buka **Kelola Toko → Cabang (Outlet)**.
2. Klik **Tambah Cabang**.
3. Isi data:

| Kolom | Keterangan |
|---|---|
| **Nama** | Nama outlet (misal "Kopi Senja — Tebet") |
| **Kode** | Kode singkat outlet |
| **Alamat** | Alamat lengkap outlet |
| **Telepon** | Nomor telepon outlet |
| **Email** | Email outlet (opsional) |

4. Simpan.

<Callout type="tip" title="Cabang utama">
  Outlet pertama otomatis menjadi **cabang utama**. Cabang utama biasanya menjadi tempat admin login dan pusat pengaturan.
</Callout>

## Status aktif & nonaktif

- **Aktif** — outlet bisa dipakai transaksi dan tampil di Aplikasi POS.
- **Nonaktif** — outlet disembunyikan/dihentikan operasinya.

<Callout type="warning" title="Nonaktifkan dengan hati-hati">
  Menonaktifkan outlet menghentikan penggunaannya, tetapi data historis (transaksi, shift) tetap tersimpan.
</Callout>

## Detail cabang

Klik cabang untuk melihat detail:

- Data outlet.
- Jumlah **shift** yang tercatat.
- **Karyawan** yang terdaftar di outlet tersebut.

<Callout type="info" title="Edit hanya oleh owner">
  Data cabang (nama, kode, alamat) umumnya hanya bisa diubah oleh **owner**. Jika Anda bukan owner, minta pemilik toko untuk mengubahnya.
</Callout>
