# Template Struk

Menu **Struk** mengatur tampilan struk yang dicetak dari Aplikasi POS. Struk diatur **per outlet** sehingga tiap cabang bisa punya format berbeda.

<Callout type="info" title="Printer diatur di POS, tampilan di Dashboard">
  Koneksi printer (Wi-Fi/Bluetooth/USB) diatur di Aplikasi POS. Tampilan dan isi struk diatur di Dashboard → Struk. Baca [Printer Thermal](/pos-app/thermal-printer).
</Callout>

## Pengaturan utama

| Pengaturan | Keterangan |
|---|---|
| **Ukuran kertas** | **58 mm** atau **80 mm** (harus sesuai printer) |
| **Font** | Pilihan jenis/ukuran font struk |
| **Header** | Teks di bagian atas struk (misal nama toko, alamat) |
| **Footer** | Teks di bagian bawah struk (misal ucapan terima kasih) |
| **Simbol mata uang** | Simbol yang dipakai (misal **Rp**) |
| **Logo** | Menampilkan logo toko di struk |

## Opsi konten struk

Aktifkan/nonaktifkan elemen yang tampil di struk:

- **Logo** — tampilkan gambar logo.
- **Alamat** — tampilkan alamat toko.
- **Kasir** — tampilkan nama kasir.
- **Referensi bayar** — tampilkan metode/nomor referensi pembayaran.
- **Pajak** — tampilkan rincian pajak.
- **Diskon item** — tampilkan diskon per item.

<Callout type="tip" title="Sesuaikan kebutuhan">
  Struk untuk kedai kopi cukup ringkas; untuk retail mungkin perlu alamat dan metode bayar. Matikan yang tidak perlu agar kertas hemat.
</Callout>

## Pratinjau struk

Gunakan **Preview** untuk melihat hasil:

- **Sample** — contoh struk dengan data dummy.
- **Real** — struk dengan data transaksi nyata (jika ada).

<Callout type="warning" title="Cocokkan ukuran kertas">
  Pastikan ukuran kertas di Dashboard **sama** dengan ukuran yang dipilih printer di Aplikasi POS (58 atau 80 mm), agar struk tercetak rapi.
</Callout>

<AccordionGroup>
  <Accordion title="Kenapa struk tercetak tidak rapi?">
    Periksa ukuran kertas (58/80 mm) di Dashboard dan di pengaturan printer POS — keduanya harus sama.
  </Accordion>
  <Accordion title="Bisa punya format struk berbeda per outlet?">
    Ya. Template struk diatur per outlet.
  </Accordion>
</AccordionGroup>
