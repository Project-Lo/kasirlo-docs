# Kode Akses Kasir

**Kode Akses Kasir** adalah kode (umumnya 8 karakter) yang dipakai untuk masuk ke **Aplikasi POS** di sebuah perangkat. Satu kode dibuat **per perangkat di outlet** — misalnya satu kode untuk HP kasir di kasir 1, satu lagi untuk tablet di kasir 2.

<Callout type="info" title="Alur login POS">
  Kasir membuka aplikasi → memasukkan **kode akses** → memilih akun karyawan → memasukkan **PIN 6 digit**. Baca [Login Kasir](/pos-app/login-cashier).
</Callout>

## Membuat kode akses

1. Buka **Kelola Toko → Kode Akses Kasir**.
2. Klik **Tambah Kode Akses** (atau **Tambah Akses**).
3. Pilih **outlet** tempat perangkat dipakai.
4. Masukkan **nama perangkat** (misal "HP Kasir 1", "Tablet Dapur").
5. Simpan — sistem membuat kode otomatis.

<Callout type="tip" title="Salin kode">
  Setelah dibuat, **salin kode akses** dan kirimkan ke perangkat kasir. Kode tampil satu kali pada saat pembuatan.
</Callout>

## Menggunakan kode akses

1. Instal Aplikasi KasirLo POS di HP/tablet.
2. Masukkan kode akses pada layar pertama.
3. Ikuti alur login (pilih kasir + PIN).

## Menghapus kode akses

Jika perangkat hilang/diganti, hapus kode akses lama:

1. Buka **Kode Akses Kasir**.
2. Cari kode yang ingin dihapus.
3. Klik **Hapus** — perangkat tersebut tidak lagi bisa login.

<Callout type="warning" title="Keamanan">
  Hapus kode akses segera jika perangkat hilang atau kasir keluar, agar perangkat tidak bisa diakses orang lain.
</Callout>

<AccordionGroup>
  <Accordion title="Satu kode bisa dipakai banyak perangkat?">
    Sebaiknya buat kode terpisah per perangkat agar mudah dikelola dan dicabut saat ada perangkat hilang.
  </Accordion>
  <Accordion title="Kode akses salah di aplikasi?">
    Pastikan kode diketik persis (termasuk huruf kapital). Jika ragu, buat kode baru dan salin ulang.
  </Accordion>
</AccordionGroup>
